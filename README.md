### Local Setup Instructions (Dashboard):

1️⃣ Clone the Repository

git clone https://github.com/sshammi/MyPortfolio.git

cd BasaFinder

2️⃣ Setup the Backend

1.cd dashboard-server

2.npm install

3.Create a .env file

4.Update environment variables in .env as needed

5.Run the backend server -
 npm run start:dev

3️⃣ Setup the Frontend

1.cd portfoliodashboard-client

2.npm install

3.Create a .env file

4.Update environment variables in .env as needed

5.Run the client -
 npm run dev
